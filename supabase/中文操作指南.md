# Supabase 建表操作指南（中文 · 纯点击步骤）

> 作用：在 Supabase 数据库里建好 App 需要的表。这一段只要跑一次，以后不用再动。
> 安全说明：本脚本「幂等」——重复跑也不会删数据、不会新建重复表，放心执行。

## 一、在网站里执行（照着点就行）

1. 打开 https://supabase.com/dashboard ，用你建库的那个账号登录。
2. 在左侧项目列表里，点开你的项目（项目名：**ai-workbench**，地址 `njsdurynltbwhxfutgub.supabase.co`）。
3. 在左侧菜单找 **SQL Editor**（翻译：「SQL 编辑器」），点它。
4. 点左上角 **New query**（新建查询），会打开一个空白编辑框。
5. 把你电脑里 `ai-workbench/supabase/schema.sql` 这个文件的**全部内容**复制，粘贴进编辑框。
   - 看不懂没关系，它只是建表命令，你照贴就行。
6. 点右上角绿色 **Run**（运行 / 播放键）执行。
7. 下方出现结果：没有红色报错、显示绿色对勾或 `Success` 就成功了。

> 提示：如果你的 Supabase 后台界面是英文，按钮名字就是上面写的英文（SQL Editor / New query / Run），对照点即可。

## 二、这段脚本到底做了啥（给你翻译一下）

**A. 7 张老表（你之前建过，这次会自动跳过，不重复建、不删数据）**
- `briefings` 每日晨报（美股夜盘 / 经济信息 / 国内大事 / AI 摘要）
- `diet` 饮食（早午晚 + 下午茶 + 饮品 + 维生素D + 肌醇 + 自定义打卡）
- `trading` 操盘复盘（操作记录 / 复盘 / AI 分析）
- `monthly_tasks` 月度事务（还信用卡 / 猫咪驱虫等）
- `calendar_events` 日历事件（一次性重要事项，带时间字段）
- `chat_sessions` / `chat_messages` AI 对话记录

**B. 给老表补的新字段（本次新增，之前没有）**
- `diet` 表加：下午茶、饮品、维生素D、肌醇、自定义打卡
- `calendar_events` 表加：时间（日计划时间轴用）

**C. 新建 2 张表（本次重点）**
- `checkin_items` 自定义打卡项：你手动加的打卡（比如「冥想」），**长期保留，不随日期清空**
- `favorites` 收藏夹：收 B站 / 抖音 的视频，带自动分类（猫 / 经济股票 / 乐高 / 做饭 / 听歌 / 其他）

**D. 安全规则（自动配好，不用管）**
- 每张表都设了「行级安全」，保证**只有你自己账号能看自己的数据**。
